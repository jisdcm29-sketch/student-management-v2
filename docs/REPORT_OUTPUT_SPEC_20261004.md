# 학생관리시스템 V2 조회/출력 모듈 시방서

작성일: 2026-10-04

## 1. 기준 자료
- 기존 Google 기반 학생관리 프로그램의 PageReport.html
- 기존 Google 기반 학생관리 프로그램의 JSReport.html
- 현재 학생관리 V2의 조회/출력 화면 및 통합 출석 조회 기능
- 현재 V2 성적관리(ScoreHub) 및 모바일/TOPIK I 동기화 구조

## 2. 설계 원칙
1. 기존 Google 기반 프로그램의 유용한 기능은 유지한다.
2. 동일 목적의 버튼과 조회 조건은 통합하여 화면을 단순화한다.
3. 현재 V2 데이터와 이전 데이터는 삭제/병합하지 않고 조회 시 통합한다.
4. 학생 종합 출력은 출석, 성적, 진도, 수업/지도 기록을 한 문서에서 확인할 수 있게 한다.
5. 출력은 현재 조회 결과를 기준으로 하며 불필요한 중복 출력 버튼을 줄인다.
6. 현재 V2의 정상 기능(출석, 성적, QR, 자동동기화)을 깨지 않는다.

## 3. 최종 조회/출력 화면 구조

### A. 학생 종합 조회 / 출력
필수 입력:
- 반
- 학생
- 조회 범위: 전체 기간 또는 시작일~종료일

조회 결과:
- 기본 정보: 이름, 전화번호, 반, 상태, 등록일, 현재/목표 TOPIK 급수
- 출석 요약: 총 수업일, 출석, 지각, 결석, 조퇴, 출석률
- 출석 상세: 날짜, 상태, 반, 출처, 메모
- 성적 요약: 서울대 누적 통과, 복습 읽기/듣기, TOPIK I 연어/문법/읽기
- 성적 상세: 서울대 과별 누적 최고, 복습 평가, TOPIK I 읽기 연습/실전
- 학습 진도: 현재 교재/과, 다음 학습 단계
- 수업/지도 기록: V2에 연결된 수업/개별지도 기록

출력:
- 학생 종합 출력 1개 버튼
- 조회한 범위와 동일한 내용 출력

### B. 반별 조회 / 출력
필수 입력:
- 반
- 조회 구분: 일별 / 주별 / 월별
- 시작일 / 종료일

조회 결과:
- 재학생 수
- 출석률 및 출석/지각/결석/조퇴 집계
- 학생별 출결 요약
- 해당 기간 수업 진행/수업 내용(연결된 경우)

출력:
- 반별 출력 1개 버튼

### C. 학생 상태 통계
필수 입력:
- 반 또는 전체
- 시작일 / 종료일

조회 결과:
- 기간 등록 학생 수
- 휴학 수
- 중단 수
- 중도포기 수
- 보관 학생 수
- 중도포기율
- 상태 변경 학생 상세

출력:
- 통계 출력 1개 버튼

## 4. 기존 Google 기반 화면에서 유지할 기능
- 반/학생 선택
- 기간별 조회
- 전체 이력 조회
- 학생 종합 조회
- 반별 출결/수업 진행 조회
- 중도 탈락/보류 통계
- 인쇄/출력
- 출석과 성적을 함께 보는 구조
- 학생 기본정보 + 출결 + 성적 + 수업 내용을 한 리포트에서 보는 구조

## 5. 통합/삭제할 불필요 요소
- 요약 조회와 학생 종합 조회는 중복도가 높으므로 학생 종합 조회로 통합
- 요약 출력과 상세 출력은 현재 조회 결과를 출력하는 하나의 학생 종합 출력으로 통합
- 학생 개인 조회에서 일별/주별/월별 선택은 제거하고 전체기간 또는 날짜범위만 사용
- 반별 조회에서만 일별/주별/월별 집계 유지
- 각 영역마다 반복되는 초기화 버튼은 화면 전체 초기화 1개로 축소 가능
- 결과 박스를 기능별로 여러 개 상시 노출하지 않고 선택한 조회 유형의 결과만 표시

## 6. 데이터 우선순위
### 출석
1. 현재 V2 Attendance
2. 같은 학생/같은 날짜에 현재 기록이 없으면 LegacyAttendanceHistory
3. 이전 기록 중 같은 날짜 중복은 최신 sourceUpdatedAt 1건 사용

### 성적
- ScoreHubSourceV2 기준
- V2 전용 학습 시트 우선 조회
- TOPIK I WRONG_REVIEW는 조회/출력에서 제외

### 학생 연결
- 전화번호를 원칙적 연결 키로 사용
- 이름이 달라도 전화번호가 같으면 동일 학생으로 연결

## 7. 구현 순서
1. 학생 종합 조회/출력 완성
2. 반별 출결/수업 진행 조회
3. 학생 상태 통계
4. 출력 레이아웃 정리
5. 성적/수업/지도 기록 추가 검증
6. GitHub 반영 전 전체 회귀 테스트
