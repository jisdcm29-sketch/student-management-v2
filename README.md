# 학생관리시스템 V2

GitHub 중심 다중교사 학생관리 시스템입니다.

## Phase 1 상태
- V1 운영본은 변경하지 않습니다.
- 이 저장소를 V2 코드의 Source of Truth로 사용합니다.
- GitHub Pages를 공통 교사용 Frontend로 사용합니다.
- Google Apps Script는 API Backend로 유지합니다.
- 교사별 Google Sheet는 서로 분리합니다.
- Phase 1에서는 실제 학생 데이터나 운영 API를 연결하지 않습니다.

## 변경관리 규칙
기능 추가/수정 전에 Google Drive의 V2 MASTER SPEC과 CHANGELOG를 먼저 갱신합니다.
데이터 구조 변경 시 DATA MIGRATION SPEC도 함께 갱신합니다.
